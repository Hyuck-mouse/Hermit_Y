# 信息收集与侦察

## 描述
在渗透测试或CTF开始时，通过多种手段收集目标网站的系统信息、隐藏路径、敏感文件等，为后续攻击提供基础。

## 触发条件
- 刚拿到目标URL，尚未进行任何测试。
- 题目描述没有给出源码，需要自行发现入口。

## 检测方法
1. **查看网页源码**：寻找注释中的隐藏提示（`<!-- TODO: /admin -->`）。
2. **检查 robots.txt**：可能泄露后台路径。
3. **扫描备份文件**：尝试访问 `index.php~`、`index.php.bak`、`.git/`、`.svn/`、`.DS_Store`、`www.zip`、`web.tar.gz` 等。
4. **识别CMS/框架**：通过响应头 `Server`、`X-Powered-By` 以及Cookie中的特定字段（如 `PHPSESSID`）识别。
5. **错误信息利用**：在URL参数中输入非法字符（如 `'`），触发错误显示路径或数据库类型。

## 常用命令
- **目录扫描**：使用 dirsearch 或御剑，常用字典为 `common.txt` 或 `directory-list-2.3-medium.txt`。
- **备份文件探测**：使用 Burp Intruder 爆破常见备份后缀：`.bak`, `.old`, `.swp`, `.~`。

## 绕过技巧
- 如果根目录禁止访问，可尝试 `./` 或 `../` 绕过。
- 使用 `%2e` 代替 `.` 尝试路径遍历。

## 附加提示
- 许多CTF题目会将Flag放在 `/flag` 或 `flag.txt` 中，如果发现文件包含点，可优先尝试读取这些文件。
